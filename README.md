# Pixel Tower Defense (Pygame)

    pip install pygame numpy
    python run.py

Controls: 1-6 pick tower | click map to place (anywhere off the road) | click tower to upgrade/sell
SPACE next wave | P pause | +/- speed | Q meteor (then click) | W time freeze | RMB/ESC cancel | U upgrade x1

Modules: config (balance knobs) | bignum | pathing | enemies (numpy pool) | waves | towers | sim (headless core)
         sprite_data/sprites | effects | render | ui | game
